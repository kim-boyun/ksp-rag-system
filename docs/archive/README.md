# 문서 아카이브

이 디렉토리는 프로젝트 개발 과정에서 생성된 기록 문서들을 보관합니다.

## 📁 포함된 문서

- **STAGE*.md**: 각 단계별 완료 보고서
- **STEP*.md**: 리팩토링 단계별 완료 보고서
- **SYSTEM_COMPLETE.md**: 시스템 완료 보고서
- **PROJECT_COMPLETE.md**: 프로젝트 완료 보고서
- **REFACTORING_COMPLETE.md**: 리팩토링 완료 보고서
- **WORKFLOW.md**: 개발 워크플로우 문서

## 📝 참고

현재 사용 중인 주요 문서는 루트의 `README.md`와 `docs/` 디렉토리에 있습니다.
