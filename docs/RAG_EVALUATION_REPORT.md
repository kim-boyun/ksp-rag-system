# RAG 시스템 평가 보고서

**평가 일시**: 2026-02-20 (재평가)  
**평가 방법**: CLI 환경에서 직접 질의 실행 후, 정해진 평가 기준으로 검토

---

## 1. 평가 기준 (요약)

- **형식·규칙**: 출처 표시, 문장 완결성, 질문에 대한 직접 답변, 사고 과정 노출 여부
- **일관성**: 동일 질문 반복 시 핵심 내용·인용 일관성
- **검색 품질**: 참고 문서가 질문과 관련 있는지, 인용한 문서 번호가 실제 반환 문서와 일치하는지
- **저관련도 처리**: 문서에 없는 주제 질문 시 고정 메시지 출력 여부

---

## 2. 실행 환경

- **명령**: `docker compose --profile server run --rm app python -m ragapp ask "질문"`
- **설정**: `.env` (server 모드, Elasticsearch, ksp_rag_index_m3, bge-m3, server_http LLM)
- **쿼리 확장**: 3개 변형, RRF(k=60) 병합, top_k=12
- **캐시**: 질의 1·3·4는 기본(CACHE_ENABLED=true), 질의 2(일관성 검증)는 CACHE_ENABLED=false로 실행

---

### 3.1 질의 1: "KSP 환경부담금 제도란 무엇인가?" (1회차)

| 항목 | 결과 | 비고 |
|------|------|------|
| 출처 표시 | ✅ | `[출처: 문서 11]`, `[출처: 문서 7]` 명시 |
| Citations 목록 | ✅ | 문서 11(페이지 27), 문서 7(페이지 33) — 동일 보고서 |
| 문장 완결성 | ✅ | 정의 문단 + 불릿 2개, 요약 문장 |
| 질문에 대한 직접 답변 | ✅ | "환경부담금 제도는 … 제도입니다" 형태로 정의 제시 |
| 사고 과정 노출 | ✅ 없음 | clean_rag_answer 적용 |
| 참고 문서 관련성 | ✅ | #1~#12 모두 환경부담금 국문모듈화보고서, RRF 0.0276~0.0328 |

**요약**: 형식·규칙 충족, 검색도 관련 문서 위주. 오염자·수익자 부담, 환경개선 재원 등 문서 내용과 부합.

## 4. 종합 평가

| 기준 | 평가 | 설명 |
|------|------|------|
| 형식·규칙 | ✅ 양호 | 출처 형식 준수, 사고 과정 미노출, 문장 완결 |
| 질문에 대한 직접 답변 | ✅ 양호 | 정의·도입 배경 질문에 맞게 답변 |
| 일관성 | ⚠️ 보통 | 동일 질문 시 주제·문서는 일관, 인용 번호·강조점은 실행마다 다름 (쿼리 확장·RRF 영향) |
| 검색·인용 일치 | ✅ 양호 | 인용한 문서 번호가 모두 Retrieved Documents 목록에 존재, 동일 보고서 내 청크 |
| 저관련도 처리 | ✅ 양호 | 관련 없는 질문에 고정 메시지만 출력, 본인 지식 답변 금지 준수 |

## 5. 개선 제안 및 반영 사항

### 5.1 반영 완료

- **저관련도 시 LLM 스킵**
  - `RETRIEVAL_MIN_SCORE`: Elasticsearch 리트리버에서 이미 사용 중. 점수를 max로 정규화한 뒤 이 비율 미만 문서 제외. `.env`에서 `0.2`~`0.5` 등으로 설정 시 저관련도 질의에서 결과가 0건이 되면 파이프라인에서 LLM 호출 없이 고정 메시지 반환.
  - **신규** `RETRIEVAL_SKIP_LLM_IF_MAX_BELOW`: 검색(및 RRF 병합) 후 상위 문서의 **최고 점수**가 이 값 미만이면 LLM 호출 없이 고정 메시지 반환. 쿼리 확장·RRF 사용 시 점수 스케일이 달라지므로, RRF 기준으로 약 `0.02`~`0.05` 구간에서 튜닝 권장. 기본값 `0`(비활성). 본 재평가에서 월드컵 질의 최고 점수 0.0164였으므로 `0.02` 설정 시 LLM 스킵됨.
- **일관성**: 동일 질문에 대한 캐시는 이미 동작 중(`CACHE_ENABLED=true`). "완전 동일 답"이 필요하면 `QUERY_EXPANSION_ENABLED=false`로 쿼리 확장을 끄면 재현성이 높아지나, recall은 쿼리 확장이 유리할 수 있음.

### 5.2 참고(추가 권장)

- **정밀 검증**: 본 평가는 형식·일관성·인용 존재 여부 위주. 도메인 전문가에 의한 "문서 N 페이지 M 내용과 답변 문장 일치 여부" 등 샘플 검증은 별도 진행 권장.
